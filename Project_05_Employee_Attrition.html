Employee Attrition Root-Cause Intelligence

Problem

Turnover is rising. Integrate performance, workload, pay, absenteeism, overtime, engagement and training data to find organisational factors tied to attrition and recommend evidence-based interventions.

Algorithm flow

InputProcessDecisionOutput
Merge HRIS, payroll, attendance, engagement survey, training records
Create features: overtime hrs, pay compa-ratio, absence days, engagement, training hrs, manager tenure
Label leavers vs stayers (12-month window)
Train interpretable model + compute feature importance / correlation
Factor effect significant (p<0.05) ?
YES → rank as root cause, find the departments where it is worst
Simulate intervention: change factor → recompute predicted attrition
Ranked root causes + interventions + projected attrition drop

Pseudocode

X = merge(hris, payroll, attendance, survey, training)
y = left_within_12m
model = LogisticRegression().fit(zscore(X), y)
importance = abs(model.coef_) ; sig = p_values(model) < 0.05
causes = sorted(features[sig], key=importance, reverse=True)
def simulate(change):                 # e.g. overtime -30%
    X2 = apply(X, change)
    return mean(model.predict_proba(X2)) 
gain = base_rate - simulate(chosen_intervention)
